# carolinapedernera.github.io

Portfolio de **Carolina Pedernera Olaeta** — community manager & realizadora audiovisual (Rosario, Argentina).

Sitio estático (HTML + CSS + JS, sin build). 

## Cómo sumar un trabajo
1. Video en `assets/video/<id>.mp4` (H.264, 720px de ancho, `+faststart`).
2. Poster en `assets/img/posters/<id>.webp`.
3. Entrada en `assets/js/data.js` (`WORKS`).

Ver local: `python3 -m http.server` y abrir http://localhost:8000
